02 / A SAFE FIRST RUN

Observe. Qualify.
Keep only what works.

Agents should not begin by suppressing real operations. Evaluation must first establish a compatible target and an economically meaningful residual after native controls.

  1. 01

    Inspect locally

    Run the supported local scan and identify expensive repeated read-only calls. Keep prompts, source values and private paths local.

    npx seenrelay scan
  2. 02

    Honor source-native controls

    Try authoritative validators, native caching and existing batching or single-flight mechanisms first. A stronger native baseline is a correct stop condition.

  3. 03

    Measure before suppression

    Use a shadow assessment for actual compatible demand, correctness, freshness and SeenRelay overhead. Do not classify synthetic results as customer savings.

  4. 04

    Use qualified evidence—or validate normally

    A matching historical observation can support a decision only within policy and scope. If anything is unknown, stale, contested, incompatible or rights-restricted, perform the normal authoritative source operation.

03 / SOURCE-BASED PROTOCOL

Two operations.
Explicit uncertainty.

CHECK compares a buyer-held known value against bounded recent observations. OBSERVE follows independently obtained source information. Neither operation is an external source fetch by SeenRelay.

POST /v1/check

Check a known value

Submit a canonical fact descriptor, existing known value and maximum age. Read the response status and provenance; never infer that a signature alone proves source truth.

SAME_OBSERVED · CHANGED_OBSERVED
CONTESTED · STALE · UNKNOWN
POST /v1/observe

Report an actual source observation

Only after your agent has legitimately acquired the source value. Preserve exact source, locator, variant, rights and time; use idempotency and appropriate observer proof.

Authoritative acquisition happens first.
No reward for OBSERVE alone.

Correctness is part of the economics.

A cheap shortcut is worthless if it crosses a tenant, misidentifies a variant, violates source rights, or acts on obsolete information. SeenRelay must remain able to say DO NOT USE.
