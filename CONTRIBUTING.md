# Contributing to SeenRelay

Thank you for your interest in SeenRelay.

## Current contribution boundary

At this stage, SeenRelay welcomes:

- bug reports;
- reproducible compatibility findings;
- integration feedback;
- documentation corrections;
- benchmark or workload reports that help evaluate the protocol in real use.

External code contributions are **not currently accepted or merged** unless a contribution agreement process has been published by the project first.

Please do not submit unsolicited implementation pull requests. They may be closed without review even when technically useful.

This temporary boundary keeps the implementation and contribution history unambiguous while the public integration surface is still stabilizing. It does not restrict independent clients that interoperate with the published SeenRelay protocol under the repository's existing licensing terms.

## Issues

Before opening an issue:

1. search existing issues for duplicates;
2. describe the observed behavior and expected behavior;
3. include the smallest reproducible example when possible;
4. remove credentials, private data, signed URLs, tokens, cookies, and other secrets.

For security-sensitive reports, do not publish exploit details, credentials, or private data in a public issue. Use the repository's published security-reporting channel when available.

## Future code contributions

If external code contributions are opened later, the repository will publish the applicable contribution terms before such contributions are accepted.

Until then, opening an issue, discussion, or other feedback channel does not by itself authorize changes to the hosted service or alter the licensing terms of the repository.
